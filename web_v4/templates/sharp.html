Evidence of informed betting is read only from real price movement: which books moved first, steam across books, key-number crossings, buybacks, and market-making vs recreational disagreement. The 0–100 score is an uncalibrated heuristic. Simulated sportsbook customers are never used as evidence. {% if s.live %}Quotes are real collected odds. Movement signals need several snapshots per game, so most games show insufficient evidence until a few days of collection exist.{% else %}In this build the quotes are demo data, so the signals demonstrate the method only.{% endif %}

Not available: reverse line movement and ticket-vs-money splits (no licensed betting-splits source), and injury news (no feed). The engine reports these as unavailable; it never estimates them.
